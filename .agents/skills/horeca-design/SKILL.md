# Royal Baltic HoReCa Express: design
1. Read root AGENTS.md, identify the exact screen/section and existing approved visual baseline. Do not redesign unrelated parts.
2. Inspect actual existing components, design tokens, fonts, colors, imagery and FR/EN/DE/RU locales before proposing changes. Respect FR default.
3. Use Product Design, Figma or UI/UX plugin when available in the running session; verify availability before claiming usage. If not available, apply this local checklist directly.
4. Define content hierarchy, spacing, type scale, responsive layout (desktop/mobile), empty/loading/error states and accessibility before coding.
5. For chef recipes, show genuine appetizing dish imagery where assets/licensing permit; meaningful title, duration, servings if verified, clear action. Do not create editorial claims like "popular" or "our chef" without confirmed source.
6. Prioritize professional B2B HoReCa presentation: real product relevance, clear CTA, consistent brand; avoid sparse unstyled text panels, generic placeholder cards and gratuitous decoration.
7. Preserve approved components; implement only requested changes and compare changed region with baseline.
8. Handoff to horeca-frontend and visual-qa. UI is not DONE solely because JSX renders.
